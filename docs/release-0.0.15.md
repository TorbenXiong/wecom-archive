## 新功能

- 远程计划采集支持持久化增量同步：首次全量读取，后续使用 5 分钟重叠窗口，仅上传新增或变化的消息及相关附件；重启后继续进度，每隔 24 小时在下一次任务中全量核对旧消息和附件变化。
- 管理员立即采集和离线导出保留全量读取；先脱敏再筛选变化，目录和成员资料变化也可单独同步。上传或进度保存失败时保留上次检查点，允许重试。

## 问题修复

- 采集端离线导出创建临时文件失败时，保留已有 `.partial`；写入或发布失败只清理本次创建的临时文件，重试不覆盖已完成的导出。
- 降低大型 JSON 和加密包在导入、编码与解码时的内存占用；附件分块校验和写入，保留原有完整性校验、旧时间格式兼容、失败清理及不覆盖已有文件的行为。单包内存仍随内容大小增长。
- 按职责整理采集宿主，保持本机采集、远程计划、升级入口和原有授权边界兼容。

## 下载

下载并运行 Windows x64 单程序 `WeComArchive.exe`。升级前正常退出旧程序，替换 EXE，并保留原有 `serverData/`、`collectorData/` 和 `source-roots.dpapi`。新目录首次运行由程序生成运行数据。

本版本保持数据库 v2 和四个归档契约兼容，第三方依赖未变，无需为本次优化重新采集。数据库快照和媒体目录索引仍完整处理；增量窗口之外的旧消息变化在全量核对时同步。备份与恢复边界见 [备份与恢复](backup-recovery.md)，验证范围见 [0.0.15 验收记录](acceptance/0.0.15-results.md)，构建和验收入口见 [README](../README.md#开发)。
