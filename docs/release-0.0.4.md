# 0.0.4 发布说明（待审阅）

## 新功能

- 本机与专属采集端支持固定间隔、每日定时计划，展示最近和下次执行时间。
- 专属采集端首次上传后收起到托盘，右键托盘图标退出；无消息变化时跳过重复上传。
- 支持会话和消息内容分别排序、排序后分页，以及 Markdown 单文件导出。
- 采集端配置草稿可跨页面保留，数据脱敏默认开启。

## 修复与文档

- 发现、密钥探针和采集移入阻塞线程，减少窗口卡顿；无页面订阅时仍保留归档版本更新。
- 未生成采集端时显示明确提示，并在构建时跟踪采集端资源。
- 更新 README、架构、能力矩阵、安全边界和实施状态。
