# 产品能力矩阵

| 能力 | Windows 采集客户端 | 中央归档服务端 |
| --- | --- | --- |
| 本地源数据发现/解密 | 实现 | 不持有源密钥 |
| DB/WAL/SHM 一致性快照 | 实现 | 不适用 |
| `MessageV1` 归一化 | 实现 | 验证并消费 |
| JSON 导出/导入 | 导出 `client-export.v1` | 校验、幂等导入 |
| CSV | writer 保留，UI 不开放 | 富筛选导出，不支持回灌 |
| 会话浏览/筛选/FTS | 不提供 | 实现 |
| 媒体预览与完整性 | 仅采集计数/关联 | 实现 |
| HTML/PDF/ZIP | 不提供 | 实现 |
| DPAPI 源密钥 | 实现 | 不接收 |
| 审计/retention/legal hold | 携带批次元数据 | 存储、检索，执行器分期实现 |
| 加密上传 | 契约预留，默认关闭 | 接收端分期实现 |
| macOS / Android / iOS | adapter 预留 | 消费相同传输契约 |
