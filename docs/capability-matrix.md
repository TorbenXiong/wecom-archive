# 产品能力矩阵

| 能力 | 普通版 Windows 客户端 | 企业版中央归档服务端 |
| --- | --- | --- |
| 本地源数据发现/解密 | 实现 | 不持有源密钥 |
| DB/WAL/SHM 一致性快照 | 实现 | 不适用 |
| `MessageV1` 归一化 | 实现 | 验证并消费 |
| JSON | 导出按会话和名称组织的 `readable-export.v1`，仅供个人阅读 | 不接收普通版 JSON；专属采集端加密包规划中 |
| CSV | 支持选择导出，防公式注入 | 富筛选导出，不支持回灌 |
| HTML / TXT | 支持离线阅读，不支持回灌 | HTML 富筛选导出；TXT 暂不提供 |
| 会话浏览/筛选/FTS | 不提供 | 实现 |
| 媒体预览与完整性 | 仅采集计数/关联 | 实现 |
| PDF / ZIP | 不提供，可通过浏览器打印 HTML | 实现 |
| DPAPI 源密钥 | 实现 | 不接收 |
| 审计/retention/legal hold | 不对外导出批次审计元数据 | 存储、检索，执行器分期实现 |
| 加密上传 | 不提供 | 专属采集端接收链路分期实现 |
| 企业加密配置 / 员工收集端生成 / 离线加密导入 | 普通版不提供；专属收集端规划中 | 规划中，当前设置页仅说明流程 |
| macOS / Android / iOS | adapter 预留 | 消费相同传输契约 |
