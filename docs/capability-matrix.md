# 产品能力

| 能力 | 工作台 | 专属采集端 |
| --- | --- | --- |
| 本机源数据发现、解密与只读快照 | 支持直接采集本机 | 支持采集所在电脑 |
| 会话浏览、成员、引用和群信息 | 支持 | 不提供 |
| 搜索与筛选 | SQLite/FTS5 全文搜索和会话内搜索 | 不提供 |
| 媒体 | 可采集、查看和搜索记录 | 按生成时配置上传文件和图片 |
| 数据脱敏 | 导出时可选 | 上传前按生成时配置执行 |
| 导出 | JSON、CSV、HTML、PDF 单文件；可导入本机 JSON | 默认直接上传；启用离线导出后可生成加密 `.wca` |
| 数据汇集 | 增量、幂等合并并保留消息修订 | 上传到指定工作台 |
| 传输保护 | 验证身份、签名和密文完整性 | RSA-OAEP-SHA256 + AES-256-GCM |
| 运行方式 | `WeComArchive.exe` 正常模式 | 同一 EXE 附加签名配置后的采集模式 |
| 审计与保留 | 保存导入和修订审计；自动保留策略尚未实现 | 不保存归档 |
| 组织身份与权限 | 当前使用访问令牌；OIDC/RBAC 尚未实现 | 使用专属上传令牌 |

会话导入支持专属采集端的加密 `.wca` 文件和工作台生成的契约 JSON；普通阅读导出文件不作为导入格式。
