## 新功能

- 会话相邻翻页、搜索结果及引用消息定位后的取页使用消息锚点，减少深页读取开销，保留原有页码和排序操作。
- 消息图片在滚动到附近时按需读取，点击可直接加载；内嵌显示与预览复用已读取内容，失败可点击重试。
- 提供可选的跨周期数据库快照低写入缓存，默认关闭；启用方式与清理边界见 [本机采集说明](local-collection-fixes.md)。

## 问题修复

- 周期采集优先使用消息中的有效本地媒体路径，需要名称或摘要回退查找时才建立目录索引；语音查找仅扫描相关 Voice 分支，减少无附件周期的固定开销。
- 数据库快照重试可复用本次仍稳定的文件副本，处理 WAL、SHM 的出现或消失，并在失败后清理工作副本，源数据保持只读。
- 修复清除旧定位高亮时可能误取消新引用定位的问题；图片附件卸载或内容、凭据变化时取消读取并释放 URL，避免迟到结果影响当前页面。

## 下载

下载并运行 Windows x64 单程序 `WeComArchive.exe`。升级前正常退出旧程序，替换 EXE，并保留原有 `serverData/`、`collectorData/` 和 `source-roots.dpapi`。新目录首次运行由程序生成运行数据。

本版本保持数据库 v2 和四个归档契约兼容，第三方依赖未变，无需为本次优化重新采集。随机页码、精确位置计数及搜索结果列表仍有扫描成本；已浏览原图在当前图片实例存续期间保留。跨周期快照缓存仅在显式设置 `WECOM_ARCHIVE_SNAPSHOT_CACHE=1` 时启用，可能保留未脱敏的原始源内容；合成对照写入减少但耗时更高，因此默认仍完整复制。

备份与恢复边界见 [备份与恢复](backup-recovery.md)，最终构建验证见 [0.0.16 验收记录](acceptance/0.0.16-results.md)，实现及已授权真实环境联合回归见 [优化验收记录](acceptance/optimization-regression-2026-11-06.md)，构建和验收入口见 [README](../README.md#开发)。
