## 行为与根因修正

- 本机采集原先由 HTTP handler 持有运行锁，handler 被取消时锁先释放，阻塞采集线程却可能仍运行。现在独立后台任务持有运行锁直到采集和归档提交完成；请求中断后仍可查询结果，第二次采集不会并发进入。
- 导入与采集支持可选 UUID 标识和已认证状态查询；记录排队、接收、执行、最终结果与脱敏错误。导入名额贯穿后台处理及清理；响应丢失后查询同一任务，不重复上传或采集。
- 归档导出也接受预生成标识，创建响应丢失时仍能查询原任务。状态和取消请求有限重试，未知结果保留标识及取消意图；弹窗“继续查询”沿用原任务，选项保持锁定。
- 界面显示阶段、已接收字节数和等待时间；结果未知时阻止误点重复执行。已确认完成后若列表刷新失败，单独提示刷新问题，不改判为任务失败。
- 导入和采集状态仅供工作台身份查询；设备身份不能登记这类记录。记录限额、终态保留及活跃记录保护有对应回归。

完整操作、接口、超时预算和保留策略见 [长任务状态说明](../long-tasks.md)。
