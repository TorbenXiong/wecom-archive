## 真实数据规模

真实来源隔离归档包含 **147,772 条消息**、17,051 条媒体元数据；实际保存 **15,918 份媒体文件**。完整备份包含 **15,925 个文件、10,871,140,457 字节（约 10.12 GiB）**。其余 1,133 条媒体原本就标记缺失，恢复保留该状态，不属于备份丢失。

正式备份仅保存在 Git 忽略的本机受控目录；受控相对位置、EXE 哈希及数据保留范围见真实演练记录。测试源码和文档不包含真实聊天、附件、账号、密钥、源路径或截图。

## 已确认边界与待验证事项

- 进程强制结束保留了操作系统和磁盘缓存，不能替代物理断电验证。当前 WAL + `synchronous=NORMAL` 在断电或操作系统崩溃后可能丢失最近提交；未验证缓存丢失、撕裂写或设备掉线。
- 当前恢复要求同机、同 Windows 用户的 DPAPI 解密能力；跨用户、跨机及重装后的密钥迁移未实现。在线一致性备份和定时自动备份不属于本轮交付范围。
- 数据库与媒体库不是一个原子事务。导入数据库失败可能保留未引用的已发布附件，不自动回收；没有承诺整个数据目录逐字节回滚。
- 真实数据专项覆盖 JSON API。实际 NTFS 写满使用合成数据调用归档存储和维护函数，未覆盖 HTTP 或加密 `.wca` 上传全过程写满，也未验证既有生产部署全部历史配置。
- 早期 Debug 真实演练留下一个没有清单的 `.partial`，不能作为有效备份。清理被自动审批以 `blocked by policy` 拒绝，未提供具体原因；继续保留，未重试或绕过。位置及原始记录见真实演练报告。此次 VHD 的临时目录已正常清理，与该残留无关。
