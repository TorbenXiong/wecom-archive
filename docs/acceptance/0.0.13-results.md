### 性能、目录和导入

- 真实归档为 853 个会话、147,491 条消息、17,021 项媒体，仅做已认证只读 API 与实际 WebView 检查。首批 50 行可用，滚动及快速点击加载完整 853 个不同会话；注入一次 503 后从原偏移重试，更新后保留选择。
- 高频词、中文内部片段、只在附件名出现的词、窗口之外的稀疏旧词、组合筛选、零命中、消息翻页及排序与参考结果一致。真实 HTTP 检查 offset 4,000/4,050 重叠和 4,095/4,096 边界；搜索未加载会话可正确定位。合成样本补验 FTS、特殊字符和共享附件。
- 真实实例用通知/错误/延迟注入验证前端，另在隔离实例用实际导入验证目录、搜索筛选及导出勾选保留。目录延迟用例的传输层遵守 abort；搜索及定位另明确测试忽略 abort 的迟到响应，不能混为同一证据。
- 合成归档初始 6,200 条消息、125 个会话、4 项不同媒体，9 次单消息更新后 6,209 条。JSON 和 `.wca` 合法/重复导入通过，正文篡改、空 JSON、损坏包均拒绝，失败后可继续。
- 保持 JSON 只传一半并并发提交 `.wca`，第二包等待；未传完断开时半包不入库。合法 JSON 附加 64 MiB 空白，观察完整接收但响应未结束后断开，后台及下一包最终完成，临时目录为空；页面及读接口仍可用。未采样完整内存曲线。

同一修复 Release 的两个独立数据、端口及 WebView 实例执行 21 组检查，源归档 6,209 条消息/125 个会话，目标从空库开始：

| 项目 | 实测结果 |

| 完整 JSON | 保留版本化契约和会话阅读视图，6,209 个不同消息 ID、125 个会话；原库导入新增/修订均 0，空库首次新增 6,209，再次未变 6,209。 |
| 其他导出范围 | 当前会话 6,009 条，组合筛选 1 条，多选两个会话 4 条，单日 201 条；均可导回原库，无新增或修订。 |
| 校验及简化 | 修改规范批次正文后返回 422，计数及修订号不变；简化阅读 JSON 不包含系统 ID 或声称是完整契约。 |
| 取消与已有文件 | 观察非空 `.partial` 后取消，清理本次暂存，不生成完成文件，旧文件哈希不变。 |
| 引用跨页 | 每页 100 条时第 60→61 页，200 条时第 30→31 页，500 条时第 12→13 页，均高亮原消息。升序同页直接高亮、不额外请求位置；升序跨页另由前端回归覆盖。 |
| 取消及重试 | 成功位置响应延迟且故意忽略 abort，手动翻页或取消后不被带回；一次注入 404 提示错误，随后真实请求可重试并高亮。 |

新增自动回归还使用 4,205 条消息和两个原批次，验证五种范围、排序、排版、脱敏、未发言成员、批次授权与保留策略、微秒时间精度、原库及空库往返、篡改拒绝、取消及已有文件保护。

### 其他回归与边界

四种格式完整导出 6,209 条；JSON 核对 ID，CSV 解析数据行和列数，HTML 核对消息节点及转义且无脚本，Markdown 包含首尾样本。成员资料、PNG 预览、合成 SILK 解码/播放进度/暂停/继续及原文件保存、TXT 字节一致性、超管关闭及 HTTP 403/重新启用通过。

所有写操作、下载、权限修改及注入均使用隔离合成实例。真实归档结束前计数和修订号未变，普通重启后基线计数可见；未保存真实聊天、账号、认证头、密钥、私人路径或截图。

未覆盖真实扬声器听感、真实默认应用打开、真实数据的新旧程序五次耗时对照、升级下载及强制退出/断电恢复。脱敏选项组合和 HTML 转义已测，但首次桌面样本未完整覆盖敏感正文与 CSV 公式正例；对应规则另有自动测试。没有在每次中间构建重复全量验收。
