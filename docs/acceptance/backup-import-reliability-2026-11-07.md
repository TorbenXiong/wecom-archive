## 实现范围

- 设置页提供退出工作台并打开维护窗口的入口；配置损坏时可通过 `--maintenance` 直接打开。维护窗口不启动服务、计划或源发现，仅提供固定白名单命令及原生目录选择。
- 备份包含独立 SQLite 快照、媒体、持久配置、当前 EXE 和存在的目录记忆；工作临时目录、原始快照缓存、WAL/SHM 和锁文件不纳入复制。文件大小、SHA-256、数据库完整性、外键、附件字节及 DPAPI 解密能力校验后才发布目录。
- 恢复只生成新目录，先保留待确认标记；确认后暂停计划、停用旧采集端并清除待执行请求，首次启动使用本机监听。直接打开备份内 EXE 或把备份设为运行数据目录均有启动保护。
- 同次导入的所有批次、目录、修订、FTS、统计和审计统一事务提交；失败后可幂等重试，失败不发送 revision 通知。已有附件同时验证实际大小和哈希。

## 回归覆盖

Rust 合成夹具覆盖消息、修订、目录、媒体、凭据和设备配置的备份恢复；WAL 中已提交记录与历史修订完整；源数据库和配置保留；后批次冲突及目录触发器故障回滚；已有附件同大小损坏被拒绝；占用源配置或恢复配置时失败并保留原文件与待确认标记；路径穿越、额外文件、缺失文件、篡改及无法解密的凭据被拒绝；相对目录与绝对目录共享同一锁。

React 回归覆盖维护动作仅在点击后执行、取消目录选择、忙碌时防止重复动作、失败清除旧成功结果、显式恢复确认及备份目录隐藏创建/启用操作。Tauri 权限测试覆盖仅允许本机维护窗口调用维护命令、拒绝其他窗口及远程 origin。

会话内临时 WebView2 CDP 专项验证手动维护、恢复待确认、备份目录自动维护、窄窗口基础布局、原生命令调用和采集命令拒绝；备份位置下创建备份及启用恢复命令被拒绝，数据目录没有生成运行文件；设置页按钮实际退出原服务并打开维护窗口。专项不操作文件选择对话框，不保存截图或正文；备份和恢复的文件行为由上述 Rust 合成夹具验证。临时脚本通过 UTF-8 传入 Node，修正了首次使用 PowerShell 默认管道编码造成的中文选择器超时。

## 边界

未读取真实聊天、执行真实恢复、模拟物理断电或真实磁盘写满，也未跨 Windows 用户进行恢复演练。DPAPI 仍要求备份所属电脑及 Windows 用户；在线备份、定时备份、跨机迁移、上传任务结果查询和断点续传不在本轮范围。

数据库与媒体文件不是一个原子事务。失败导入可能保留已经发布但尚未引用的附件，不自动回收，以免删除并发采集正在复用的内容。具体边界见 [导入可靠性](../import-reliability.md)，维护操作及旧版本文件锁限制见 [备份与恢复](../backup-recovery.md)。
