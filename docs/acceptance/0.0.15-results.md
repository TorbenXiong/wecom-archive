64 MiB 合成附件的最大阶段堆峰值（MiB）：

| 阶段 | 旧分配策略 | 当前 API |
| --- | --- | --- |

## 审阅发现与修复

采集端离线导出在独占创建 `.partial` 失败后仍无条件尝试删除该文件，可能误删已有临时文件。这一逻辑在宿主拆分前已存在。本轮将文件写入封装为内部函数，只有成功创建后才取得清理权，并在原子发布前关闭文件。

新增用例 `offline_package_preserves_existing_files_and_cleans_own_partial_before_retry`：保持旧写入逻辑时，预存临时文件被删除，实际 Rust 用例以退出码 101 失败；修复后同一用例通过，同时验证发布冲突保留已完成文件、仅清理本次临时文件及成功重试。

迁移审计保留字面量与属性比较，允许内部可见性、显式 imports、command 限定路径及 rustfmt 尾随逗号。除说明的离线导出修复外，176 个原生产代码项和全部 56 个原测试/辅助项保持一致，保留 50 个原根测试入口及 `tests::authorized_real_*` 精确入口；新增一个内部持久化函数和一个根回归用例。

## 覆盖边界

- 当前测试覆盖本机及隔离合成实例，不替代真实跨电脑部署、长期无人值守、物理断电或跨用户 DPAPI 迁移验收；24 小时核对由回归测试验证，没有实际等待 24 小时。
- 真实媒体用例沿用项目断言，允许源端附件缺失，不保证本机全部历史附件完整。真实环境结果来自版本升级及离线导出修复前相同的采集实现，未在最终 EXE 上重跑。
- 未测试接近 2 GiB 上限的请求；完整明文、密文和部分契约对象仍随单包大小增长，没有固定内存上限的保证。
- 未测试真实扬声器听感、真实默认应用打开或发布后的在线升级下载与替换。
