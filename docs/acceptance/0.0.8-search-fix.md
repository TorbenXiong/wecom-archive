# 0.0.8 搜索修复验收（2026-10-12）

本次移除会话时间线中的“搜索当前会话消息”输入框及其当前页过滤逻辑。消息排序、页码和引用定位继续保留。

全局搜索保留原 FTS 分词匹配，增加正文包含匹配，补足中文连续文本、词中片段等漏搜情况。正文与附件名称使用转义后的 LIKE 参数，百分号、下划线、反斜杠按字面搜索。检索依据为已入库的正文和附件名称；不检索图片内文字、未入库的源记录、会话名或发送人名。

全局搜索每批读取 50 条，新增“加载更多结果”。服务端接受可选 offset，原调用不提供 offset 时仍从第一页开始，响应结构保持兼容。改换关键词、排序或登录身份时重新从第一页加载；取消的旧请求不覆盖当前结果。界面显示已加载数量，不能当作精确命中总数。

四个版本化归档契约、数据库版本 v2 与产品版本 0.0.8 不变。无需重新导入已有归档即可使用正文包含匹配。未新增依赖或改动锁文件。

优先验收：

1. 打开会话，确认当前会话搜索框已移除，翻页和升降序仍正常。
2. 从已归档的中文长句中取连续 2–4 个字检索；再用英文词中片段与大小写变体检索，确认目标能出现。
3. 检索超过 50 条的关键词，加载更多，确认较早记录也能查看；打开第二批结果，确认定位正确。
4. 加载第二批后改换关键词，确认从第一批重置，旧词结果不混入；快速输入多个关键词，确认旧请求不覆盖新结果。
5. 检索包含 `%`、`_`、反斜杠的正文与附件名，确认字符没有作为通配符使用；正文和附件同时命中只返回一条消息。
6. 测试无命中词、升降序、引用消息与重启后的旧归档，确认不会误报、漏页或重复。

性能边界：正文包含匹配需要额外扫描，较大的归档可能比原 FTS 独立查询耗时更长；本次优先修复漏搜，没有引入新的子串索引。常见词、大结果集的检索及结果定位仍需后续性能优化。请反馈消息量、关键词长度/语言、首批耗时与加载更多耗时，避免提交真实聊天正文或私人路径。
