# 隐私与安全边界

## 采集

- 仅处理用户有权归档的数据，采集前展示组织、用途、范围和员工告知。
- 源数据库只读；DB/WAL/SHM 先复制到系统临时目录，再校验和解析。
- 工作台本机采集不离开本机服务。专属采集端仅在用户点击上传后连接签名配置中的服务端 URL，不含遥测、更新检查或第三方资源。
- 本机采集和专属采集端完成或失败后均清理临时快照；专属采集端不在 exe 同级创建 `userData`。
- 数据脱敏启用时，在上传前不可逆替换账号、密码、令牌、联系方式和疑似凭据片段；文件名和图片名保留。

## 归档服务

- 默认只监听 `127.0.0.1:8787`。需要内网或外网采集时，应通过 HTTPS 反向代理暴露已认证 API；访问令牌和私钥由 Windows DPAPI 保护。
- 只接受通过身份、签名、密文完整性、组织、密钥版本和归档契约校验的上传包。
- 媒体按内容哈希验证并存储；重复批次幂等处理，冲突批次拒绝写入。
- 错误响应使用稳定错误码，不返回数据库内容、密钥、内部路径或调用栈。
- HTML 导出全量转义并禁止脚本和远程资源；CSV 防公式注入；所有导出使用 `.partial` 原子完成且不覆盖已有文件。

## 日志和测试

日志只记录版本、阶段、计数、哈希前缀和错误码。真实聊天、账号、密码、令牌、加密密钥、私人路径和截图不得写入日志、测试产物或仓库。

## 尚未实现的组织级能力

当前访问控制适用于受控单节点部署。OIDC、RBAC、自动保留、legal hold、删除执行器和不可变审计存储尚未实现；在这些能力完成前，不应将当前版本视为完整合规归档平台。
