## 新功能

- 新增“归档健康”：查看消息范围、媒体缺失原因、不支持的消息类型及磁盘余量，并可手动只读校验数据库和已采集附件的大小、SHA-256。
- 新增持久任务中心：统一查看采集、上传、导入、导出和校验历史，支持筛选、分页和按需展开详情；重启后保留已确认结果，未确认任务显示“结果待核对”，不自动重跑。

## 问题修复

- 工作台原任务查询可回读持久结果，相同任务标识不会因服务端重启或内存记录过期而重新登记；写盘异常会明确提示。
- 加强历史记录恢复校验，拒绝缺少对应结果的完成记录，以及非法标识、状态和时间，保留异常文件供恢复检查。
- 精简健康页、任务中心、本机导出、采集端及设置页面的常驻说明；编号、错误码和低频信息按需展开，自动刷新保留任务详情，并改善窄窗口布局。

## 下载

下载并运行 Windows x64 单程序 `WeComArchive.exe`。升级前正常退出旧程序，替换 EXE，并保留原有 `serverData/`、`collectorData/` 和 `source-roots.dpapi`。新目录首次运行由程序生成运行数据。

本版本保持数据库 v2 和四个归档契约兼容，第三方依赖未变，无需重新采集。任务历史从本功能启用后开始记录，保存在实际数据目录的 `task-history/`，需随完整数据目录一并备份。

持久历史不恢复后台线程或执行进度；管理端上传历史也不改变设备确认接口原有的重启边界。校验仅覆盖已归档内容，不保证源端完整，也不会自动补采、删除或修复文件。

功能及边界见 [归档健康与任务中心](archive-operations.md)、[长任务状态与超时协调](long-tasks.md) 和 [备份与恢复](backup-recovery.md)，最终构建及验证范围见 [0.0.18 验收记录](acceptance/0.0.18-results.md)，构建和验收入口见 [README](../README.md#开发)。
