## 新功能

- 提供离线桌面验收、授权真实环境验收和 Windows 单 EXE 打包入口，使用本机已有工具与依赖。

## 问题修复

- 设置、计划和采集端配置保存成功后再切换运行时状态及日志级别，保存失败保留原设置；并发修改访问令牌时重新校验当前凭据。
- 加固配置恢复：保留上一版配置，主配置损坏或缺失且存在恢复证据时停止启动；已有归档缺少访问令牌时停止启动。
- 导入接收或等待名额超时后清理临时文件，释放名额并允许重试。
- 导出保留已有同名临时文件，失败仅清理本次创建的文件，并支持重试。
- 修复连续定位同一条消息时，旧定时器导致新高亮提前消失的问题。

## 下载

下载并运行 Windows x64 单程序 `WeComArchive.exe`。升级前正常退出旧程序，替换 EXE，并保留原有 `serverData/`、`collectorData/` 和 `source-roots.dpapi`。新目录首次运行由程序生成运行数据。

本版本保持数据库 v2 和四个归档契约兼容，第三方依赖未变。备份与恢复边界见 [备份与恢复](backup-recovery.md)，构建和验收入口见 [README](../README.md#开发)。
