# 实施状态

以下内容用于 `0.0.3` 发布前确认，状态为 2026-09-17。

| 范围 | 状态 | 验证 |
| --- | --- | --- |
| 单一 EXE 的工作台与采集端运行模式 | 已验证 | 入口判断、签名配置和单二进制 release 构建 |
| Windows 发现、快照、隔离密钥探针与解密 | 已验证 | 合成夹具和本机企业微信脱敏采集测试 |
| 工作台本机采集与专属采集端 | 已验证 | 密钥轮换、直接上传、流式媒体采集和数据脱敏测试 |
| 在线上传与离线 `.wca` 导出 | 已验证 | 采集端配置、加密包生成、服务端导入和前端交互测试 |
| 多采集端增量合并 | 已验证 | 认证、篡改、幂等、冲突、修订和并发写入测试 |
| 会话工作台 | 已验证 | 全局搜索定位、成员检索、引用、群信息、媒体、分页和双向滚动跳转测试 |
| 图片与文件 | 已验证 | 真实媒体采集、内容哈希回读、图片预览和文件打开链路测试 |
| JSON/CSV/HTML/PDF 单文件导出 | 已实现 | 脱敏、简化、美化和紧凑输出测试；PDF 依赖本机 Edge，尚未做视觉验收 |
| 企业级身份与保留策略 | 未实现 | 当前为单节点访问令牌；OIDC、RBAC、retention 和 legal hold 执行器待后续版本 |
| 大规模性能 | 未验证 | 尚未完成 50 万消息基准测试 |
