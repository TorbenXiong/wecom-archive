# 实施状态

当前版本 `0.0.13`。用户变化见 [版本说明](release-0.0.13.md)，操作标准见 [验收清单](acceptance-0.0.13.md)，构建及历史验证范围见 [验收记录](acceptance/0.0.13-results.md)。

## 当前能力

- 会话首批加载 50 条，滚动或手动继续加载；失败保留列表和偏移，更新及重试不会被旧响应覆盖。搜索会话筛选、多选导出和当前会话在目录刷新后保留选择。
- JSON 与 `.wca` 上传在认证后共用一个导入名额，接收、读取、解密、校验及归档串行进行；耗时工作在阻塞线程执行。接收取消及处理失败清理临时文件，调用方断开后后台任务仍持有名额直至结束。
- 搜索优先检查按时间排列的有限窗口，保留正文包含、中文片段、FTS 分词及附件名匹配；不足一页或超过窗口时执行完整查询。方法和前后对照见 [搜索基准](search-api-benchmark.md)。
- 服务端完整 JSON 保留可导入契约及会话阅读视图，包含原批次授权证据、保留策略、目录和完整校验。按批次暂存并流式写入，取消清理，不覆盖已有文件；重复路径脱敏保持幂等。
- 引用消息按当前排序和页大小跨页定位、高亮，支持取消和失败重试；翻页、切换会话或排序后忽略迟到响应。
- 本机语音转写读取、SILK 采集和离线播放、撤回显示沿用 `0.0.12`，限制及历史验证见 [该版验收](acceptance-0.0.12.md) 和 [本机采集说明](local-collection-fixes.md)。

## 兼容性与限制

数据库仍为 v2，四个版本化归档契约的字段语义兼容，第三方依赖未变。`Cargo.lock` 只同步本地工作区版本；默认离线和访问权限边界保持不变。

- 加密导入仍整体解析，单包内存随包大小增长；没有新增导入取消按钮或排队进度。
- 会话尚未虚拟化。OFFSET 深分页、稀疏及零命中查询、计数和筛选导出仍可能扫描大量记录，搜索窗口不是原表扫描次数的上限。
- 完整 JSON 同时包含契约批次和会话阅读视图，文件可能变大；服务端仍为媒体元数据导出，不额外嵌入附件字节。迁移离线媒体需保留原媒体库。
- 旧程序生成的不含契约的服务端阅读 JSON 需重新导出；简化 JSON 仅供阅读。正常升级保留 `serverData/` 和已有配置，无需为本版优化重新采集。
- SILK 播放限制为 10 MiB、10 分钟；不提供自动语音识别。本地没有转写或语音缓存时不能自动补齐；无明确撤回标志时不猜测事件对应的原消息。

## 验证与发布

`0.0.12` 修复候选已通过前端 102 项、Rust 单元 177 项及 21 组隔离桌面复验。`0.0.13` 初次版本构建的源码、EXE、健康接口和“关于”显示一致；这些历史结果与整理后最终验证分开记录，不能重复计数。

提交准备包含最终代码复审、自动检查、前端和 Windows x64 Release 重建及单 EXE 包校验。发布信息沿用历史四段格式，Release 只附加 `WeComArchive.exe`，更新器使用 GitHub 资产 digest 校验。最终结果统一维护在 [验收记录](acceptance/0.0.13-results.md)，不在状态页重复记录过程日志和每个中间包。
