# 实施状态

当前版本 `0.0.16`。用户变化见 [版本说明](release-0.0.16.md)，构建及验收入口见 [README](../README.md#开发)，本版验证范围见 [0.0.16 验收记录](acceptance/0.0.16-results.md)。

## 当前能力

- 采集宿主按命令、状态、配置控制、调度运行、采集组装及源数据投影拆分模块；`lib.rs` 保留兼容公开入口。原测试名称及白名单权限沿用，真实验收脚本无需改动。
- 采集端离线导出仅在成功独占创建后清理本次 `.partial`，创建失败保留已有临时文件；发布失败保留已完成文件并允许重试。
- 远程计划支持持久化增量检查点、5 分钟重叠窗口和 24 小时全量核对，仅上传变化消息及相关附件；上传或进度保存失败不推进。先脱敏再筛选，独立比较目录与成员资料；离线导出开启时仍保留全量本地结果。复用现有 SQLite 依赖和归档契约，不增加网络入口。
- 媒体目录索引仅在名称或摘要回退查找时建立，本次采集内复用；无附件或本地路径可直接命中的周期跳过通用索引。语音查找只遍历已授权 Voice 相关分支，媒体索引不跨周期缓存。数据库快照仍完整读取源文件，媒体回退查找仍有目录扫描成本。
- 提供可选的跨周期快照低写入模式：显式设置进程环境变量 `WECOM_ARCHIVE_SNAPSHOT_CACHE=1` 后，在 `snapshot-cache/` 中按源账号保留一份原始副本。文件锁独占缓存，移入本次工作目录后完整比对源文件，仅写变化的 64 KiB 块并截断过期尾部；校验通过后才解析，退出读取阶段时归还原始副本并清理派生文件。元数据相同也不跳过跨周期内容比对；缓存占用或无效时回退完整复制。启用后，采集端计划从首次任务使用，工作台本机计划从带增量游标的周期使用并建立缓存。合成对照减少了内容写入但构建快照耗时增加，因此默认保持完整复制。
- 同次稳定性重试可复用复制前后及重试前元数据一致的私有副本，变化或复制失败的文件重新处理。动态检查 WAL/SHM 集合并移除消失旁车的旧副本，失败清理本次目录。原始缓存可能含未脱敏内容，隐私及清理边界见 [安全说明](privacy-security.md)。
- 会话首批加载 50 条，滚动或手动继续加载；失败保留列表和偏移，更新及重试不会被旧响应覆盖。搜索会话筛选、多选导出和当前会话在目录刷新后保留选择。
- JSON 与 `.wca` 上传在认证后共用一个导入名额，接收、读取、解密、校验及归档串行进行；耗时工作在阻塞线程执行。接收取消及处理失败清理临时文件，调用方断开后后台任务仍持有名额直至结束。
- 大包处理减少完整副本：JSON 直接解析契约并跳过附加阅读视图，保留旧时间格式及原校验；加密包借用输入中的十六进制字符串并一次解码到精确大小的缓冲，序列化与校验使用流式哈希。附件每块最多解码 64 KiB，逐附件、逐批次写入后释放；采集端复用只读采集结果。测量范围见 [大包内存基准](package-memory.md)。
- 搜索优先检查按时间排列的有限窗口，保留正文包含、中文片段、FTS 分词及附件名匹配；不足一页或超过窗口时执行完整查询。方法和前后对照见 [搜索基准](search-api-benchmark.md)。
- 服务端完整 JSON 保留可导入契约及会话阅读视图，包含原批次授权证据、保留策略、目录和完整校验。按批次暂存并流式写入，取消清理，不覆盖已有文件；重复路径脱敏保持幂等。
- 引用消息按当前排序和页大小跨页定位、高亮，支持取消和失败重试；翻页、切换会话或排序后忽略迟到响应。
- 会话消息相邻翻页使用 revision 绑定的消息锚点，搜索命中与引用定位后从目标附近读取对齐页；随机页码及失效锚点回退 OFFSET。精确位置计数使用现有复合索引的元组范围条件，接口数组及定位响应保持兼容，无数据库迁移。方法、对照及计时边界见 [深分页与定位](message-pagination.md)。
- 消息图片在进入消息滚动视区上下 120 px 范围时读取；点击可直接加载，预览与可见性通知共用请求和已加载 URL。图片卸载、凭据或内容变化时中止读取并释放 URL；失败可点击重试。行为、边界和验证见 [图片按需加载](image-loading.md)。
- 本机语音转写读取、SILK 采集和离线播放、撤回显示沿用 `0.0.12`，限制及历史验证见 [该版验收](acceptance-0.0.12.md) 和 [本机采集说明](local-collection-fixes.md)。

## 兼容性与限制

数据库仍为 v2，四个版本化归档契约的字段语义兼容，第三方依赖未变。`Cargo.lock` 只同步本地工作区版本；默认离线和访问权限边界保持不变。

- 加密导入仍整体解析，单包内存随包大小增长；没有新增导入取消按钮或排队进度。
- 会话尚未虚拟化。随机页码和搜索结果列表的 OFFSET 深分页、精确位置与筛选计数、稀疏及零命中查询、筛选导出仍可能扫描大量记录，搜索窗口不是原表扫描次数的上限。
- 完整 JSON 同时包含契约批次和会话阅读视图，文件可能变大；服务端仍为媒体元数据导出，不额外嵌入附件字节。迁移离线媒体需保留原媒体库。
- 旧程序生成的不含契约的服务端阅读 JSON 需重新导出；简化 JSON 仅供阅读。正常升级保留 `serverData/` 和已有配置，无需为本版优化重新采集。
- SILK 播放限制为 10 MiB、10 分钟；不提供自动语音识别。本地没有转写或语音缓存时不能自动补齐；无明确撤回标志时不猜测事件对应的原消息。
