## 新功能

- 本机采集支持单次选择数据脱敏；“包含全内容”在同一任务中完成消息、图片和附件采集，并显示进度。
- 人员名片展示已缓存的企业、部门、职务、邮箱、工号、手机、电话、座机、个性签名及企业扩展资料；联系方式位于工号下方。
- 会话展示富文本表情、应用通知卡片和语音占位；附件支持保存、默认应用打开及可执行文件运行确认。

## 问题修复

- 修复消息修订反复回到历史内容时整批导入回滚，以及同一来源 IP 的采集端互相删除的问题。
- 修复短时断网后采集端退出、本机长任务增量时间边界遗漏消息的问题；失败不推进采集游标。
- 修复局域网、自定义端口和 IPv6 工作台的桌面命令授权，并避免心跳、上传令牌出现在进程参数中。
- 修复富文本表情后的数字丢失，补充图片缓存、附件摘要与本地路径关联，保留后续仅文本采集时已归档的媒体。
- 修正文档、个人应用、临时和系统会话分类，补充无名群的成员组合名称，并统一列表与时间线的类型标签。
- 补充联系人二进制资料解析；企业显示于姓名下方，职务在资料列表展示。未缓存及仅按需显示的号码仍可能缺失。

## 下载

下载并运行 Windows x64 单程序 `WeComArchive.exe`。新目录首次运行会在 EXE 同级创建 `serverData/`；升级时先退出旧程序，替换 EXE 并保留原有数据和 `source-roots.dpapi`。

本版本保持数据库 v2 和归档契约兼容。重新采集可补充旧归档缺失的内容；已有采集端需重新生成或升级后才包含本次修复。详细操作见 [人工验收清单](https://github.com/TorbenXiong/wecom-archive/blob/0.0.11/docs/acceptance-0.0.11.md)，离线资料限制见 [本机采集说明](https://github.com/TorbenXiong/wecom-archive/blob/0.0.11/docs/local-collection-fixes.md)。
