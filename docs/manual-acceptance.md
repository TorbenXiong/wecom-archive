# 人工验收清单

本页是当前功能的操作标准，不代表各项已在当前构建执行。自动测试和构建入口见 [README](../README.md#开发)，已执行结果见 [可靠性验收记录](acceptance/0.0.17-results.md)。

## 准备与数据保护

1. 记录待测 EXE 和旧端的版本、SHA-256；版本以 `package.json` 和“设置 → 关于”为准。正常退出旧程序及托盘后再替换 EXE，保留 `serverData/`、`collectorData/` 和 `source-roots.dpapi`；重要归档先按 [备份与恢复](backup-recovery.md) 备份。
2. 新包在独立目录启动，初始只放一个 `WeComArchive.exe`。旧、新工作台使用不同数据目录和端口；确认 `WECOM_ARCHIVE_SERVER_DATA` 没有指向原工作台。需要沿用加密包绑定或 DPAPI 凭据时，使用停机后复制的测试副本及同一 Windows 用户。
3. 导入、导出、设置修改和故障注入使用合成数据或授权测试副本。准备至少 120 个会话、5,000 条消息，以及同时间消息、跨页引用、共享附件、稀疏词和已知搜索目标；不具备条件的项目记录“未覆盖”。
4. 真实企业微信采集、真实源与归档对照及远程采集仅在明确授权范围内进行。源 DB/WAL/SHM 始终只读，不为造负样本修改源库；损坏、歧义和异常数据使用合成副本。不得将正文、账号、认证头、密钥、私人路径或截图留作测试产物。

## 本机合成数据或隔离归档

| 检查 | 操作与通过标准 |
| --- | --- |
| 启动与升级保留 | 启动、退出后重开，核对版本、会话/消息/媒体计数及配置。全新工作台首次运行只生成 `serverData/`，不生成 `collectorData/`；服务随正常退出停止。 |
| 归档健康 | 主导航进入健康页，核对范围、缺失原因、不支持类型与磁盘余量。手动校验后核对数据库与附件结果；仅在合成副本中制造同大小文件损坏、文件缺失，结果须能区分且恢复原文件后重新通过。校验不读取源库或补采。 |
| 持久任务中心 | 按类型/状态筛选并翻页，刷新和重启后已确认结果保留。重启前未确认记录显示“结果待核对”；相同 UUID 不能重新登记，不自动重跑。导出历史摘要与成品一致；任务记录不得含正文、凭据或完整路径。 |
| 会话按需加载 | 超过 50 个会话时首批 50 行可用，不自动读完整目录；滚动及重复点继续加载无重复、遗漏或选择跳动，末尾停止请求。阻断追加或刷新后保留列表及偏移，可从原处重试。 |
| 目录刷新与选择 | 选首批外会话、搜索会话/发送人筛选及导出多选，再由另一认证客户端导入；刷新后保留选中项和名称，多选可取消且计数正确。延迟旧响应后切页或刷新，迟到结果不能改写新目录。 |
| 搜索匹配 | 用高频词、中文词内片段、英文内部片段和大小写变体、附件名、稀疏旧词及零命中词核对已知目标。正文与附件同时命中不重复，共享附件的不同消息都保留；无本地附件字节也能按归档名称搜索。 |
| 搜索特殊值与边界 | 核对 `cafe`/`café`、多词分词、`100%_value`、`C:\fixture\files`、双引号及无关对照，无语法错误或通配扩散。组合会话、发送人、类型、附件和日期后同时满足条件；重置完整，错误日期范围有提示。 |
| 搜索分页与取消 | 经工具栏或 `Ctrl+Alt+F` 搜索至少三批，升降序及同时间消息稳定有序；辅助请求的 offset 4095/4096/4100、limit 1/50 与完整结果切片一致。延迟词 A 后改词 B、清空或关闭，旧结果不回流；不提前批量定位全部结果。 |
| 定位与引用 | 点击未加载会话中的搜索命中和跨页引用，按当前升降序及每页 100/200/500 条定位、高亮；同页引用不额外定位。取消、手动翻页或切换会话后迟到定位不覆盖新选择，失败可重试。 |
| 合法及重复导入 | 导入完整契约 JSON 和同绑定 `.wca`，内容、目录及计数正确；重复导入新增为 0，未变内容不形成修订。阅读型简化 JSON 不作为可导入正例。 |
| 非法及失败后重试 | 在合成文件中修改消息正文但不重算校验，另测空文件和坏包；拒绝且不入库，只清理本次接收文件。随后合法小包可成功导入，不能删除或覆盖其他操作的 `.partial`。 |
| 慢包及断开等待 | 两个认证客户端先发慢包再发小包，至少一次混用 JSON/`.wca`；后包等待，无丢包或死锁，期间界面可交互。半包断开后不入库、可重试；接收完成后断开等待，后台继续且持有名额至任务结束，重复导入仍幂等。 |
| 未知结果与续查 | 在测试副本受控阻断已接受任务的响应/状态查询，确认“结果暂未确认”或“继续查询”保留原 UUID。恢复后只查询原任务，不重传文件或重新采集；导出选项保持锁定。结束导入/采集跟踪不代表取消后台任务。 |
| 导出范围与往返 | 当前会话、当前筛选、多选会话、日期及全库五种范围均不受已加载目录或消息页限制；完整 JSON 可导回原库和空库，原库无无故新增/修订，篡改仍拒绝。服务端 JSON 只含媒体引用，迁移离线媒体须保留原媒体库。 |
| 导出内容与取消 | 四种格式、独立排序、简化/美化/脱敏开关及超过 4,096 条的输出范围、计数和顺序正确，转义及 CSV 公式防护有效。`.partial` 已产生时取消，只清理本次暂存，保留既有成品和其他操作的临时文件；完成后再取消不删除成品。 |
| 权限与维护保护 | 关闭超管后目录可见，消息、搜索、导出隐藏且接口拒绝越权；重新开启后恢复。按 [备份与恢复](backup-recovery.md) 在测试副本检查独立维护窗口、校验、恢复到新目录及待确认保护；失败保留原文件，确认前不启动旧计划。 |
| 附件打开与保存 | 普通文件能打开、保存；保存不执行文件。可执行附件打开前需确认，取消不运行；不为验收安装软件。 |

## 真实采集、音频与撤回

仅使用明确授权的测试账号、会话及已缓存样本。无需修改真实库即可核对的项目现场对照；缺少样本时使用合成回归或记录未覆盖。

| 检查 | 操作与通过标准 |
| --- | --- |
| 全内容与文本采集 | 先在企业微信下载测试图片/附件，再执行“包含全内容”；进度结束后文字、关系、媒体一起可用，没有后台补采任务。检查原图、自定义表情及重命名缓存附件；再执行仅文本采集，既有媒体仍可用，源缺失时明确不可用。 |
| 脱敏及富文本 | 用虚构敏感值分别开关本次脱敏选项，检查占位符；表情、纯数字、空格及重复文本顺序完整，应用通知按允许格式显示。 |
| 会话分类及名片 | 对照文档、个人应用、无名群、临时会话和系统通知的标题及标签。名片企业、部门、职务、联系方式等顺序和空值处理正确；未落入本机缓存的按需号码不作为通过要求。 |
| 语音转写 | 对已有本地转写的语音重新采集，确认显示、搜索及完整 JSON 的 `message_type=audio`、`raw_type=16`、`body_text` 正确。单纯升级不补写旧归档；无转写保留占位，旧库及孤立转写不产生多余消息。 |
| 实际听音及播放 | 对本机已缓存的语音执行全内容采集，核对下载图标、总时长、气泡及转写；实际听音确认内容。点击播放、暂停、继续均正常，播放另一条时前一条暂停；结束恢复总时长，切页停止，断网仍可播放且不调用系统应用。 |
| 语音保存及保留 | 下载图标只保存 `.silk` 原文件，不触发播放；字节与本地对应缓存一致，临时 WAV 不替换原文件。解码失败或超过 10 MiB/10 分钟播放限制时仍可保存；仅文本采集、缓存过期或同资源转写更新不丢失已归档音频。 |
| 语音缺失与歧义 | 缓存缺失、文件头/大小/摘要不符及多候选歧义保持不可用，不匹配其他账号或仅名字相似的缓存。不提供自动语音识别，不把单个样本通过推广为所有版本或编码通过。 |
| 撤回与历史保留 | 对源中已有显式撤回标志的消息重新采集，界面显示已撤回并隐藏正文及附件操作；`2063` 仅作撤回通知，数字或删除标志不得误撤回无关消息。缺少可验证原消息关联时不承诺补齐，界面隐藏不删除历史正文/媒体。 |

## 多设备、网络与升级

| 检查 | 操作与通过标准 |
| --- | --- |
| 多端与连接恢复 | 在授权的两台电脑或虚拟机上，经同一 NAT/代理运行不同测试实例，多轮心跳/上传及重启一端后两条设备记录仍保留。断线至少一次心跳后恢复应自动重连；控制配置过期时暂停新采集，恢复有效配置后继续。单机互斥测试不能替代双端。 |
| 桌面来源权限 | 在测试副本的回环、局域网、自定义端口及可用 IPv6 地址验证退出和检查更新命令；其他来源页面不能获得命令权限。采集端关闭窗口后驻留托盘，托盘退出后进程结束。 |
| 升级与回滚 | 使用已授权、可信的本产品更新源，按 [升级测试方案](update-test-plan.md) 检查工作台替换、失败回滚、采集端签名升级和身份/计划保留。缺少双端、网络或可信升级源时记录未覆盖，不临时安装工具或发布测试资产。 |

逐项记录“通过 / 失败 / 未覆盖”、版本、真实或合成数据、步骤、规模及脱敏错误。物理断电、跨 Windows 用户恢复和真实磁盘写满不由本清单默认执行；专用故障演练与限制见 [存储故障演练](storage-fault-drill.md)。单包导入内存可随大小增长，性能比较需同机同数据，不能把未测场景记为通过。
