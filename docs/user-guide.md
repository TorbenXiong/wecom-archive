# 使用指南

## 本机导出与归档

1. 打开 `WeComArchive.exe`，在“本机”选择格式，点击“开始导出”。
2. 需要在工作台查阅时，进入“会话”，点击“采集本机”，选择“仅采集文本”或“包含全内容”。
3. 使用搜索框查找记录，按会话、发送人、消息类型和日期筛选；点击结果定位原消息。

程序自动查找当前 Windows 用户的企业微信数据。找不到时，可填写企业微信设置中的存储目录；采集成功后会加密记住，最多保存 3 条。手动重试只扫描所填目录，须为本机磁盘子目录，不接受整盘根目录、网络路径或父目录跳转。

源数据库通过只读副本解析，不修改企业微信数据。图片、文件和语音是否可用，取决于本机缓存；程序不会从企业微信服务器补下载。语音支持播放已采集的 SILK 文件、保存原文件，以及展示已有转写文字。

目录发现、缓存和会话分类限制见[本机采集说明](local-collection-fixes.md)。

## 选择导出方式

| 需求 | 选择 |
| --- | --- |
| 在浏览器阅读 | HTML |
| 用表格整理 | CSV |
| 保存为文档 | Markdown |
| 后续重新导入工作台 | 完整 JSON，关闭“简化信息” |

工作台支持导出当前会话、筛选结果、多选会话、日期范围或全部档案。会话顺序与消息顺序可分别设置。

默认启用“数据脱敏”“简化信息”和“美化信息”。简化导出保留会话、发送人、时间、类型、正文和附件名称；简化 JSON 仅供阅读。导出为单个文件，不覆盖已有文件。

“会话 → 导入”支持专属采集端生成的 `.wca` 文件和完整 JSON。重复消息会合并，变化内容保留修订；失败可重试，边界见[导入可靠性](import-reliability.md)。

**完整 JSON 不包含服务端附件字节，不能替代完整备份。**

## 多台电脑与定时采集

1. 在“采集端 → 生成默认配置”设置服务端地址、采集范围和脱敏选项，生成已绑定的采集端。
2. 将采集端交给有权归档的用户运行，无需再次填写服务端地址或密钥；也可导出 `.wca` 文件后离线导入工作台。
3. 在“采集端管理”设置固定间隔或每日定时，查看在线状态、最近成功和下次执行。

计划默认关闭。远程计划启用后先采集并上传一次，再按计划执行；修改通过心跳同步。首次全量读取，随后上传新增或变化内容，每隔 24 小时在下一次任务中全量核对。失败不推进进度，无变化时跳过上传。

远程“最近成功”表示上传成功时间；本机计划显示采集成功时间。关闭采集端窗口会收起到托盘，右键“退出采集端”才会停止。工作台隐藏后可继续后台运行，退出工作台则停止服务与任务。

上传结果待确认时，按界面提示继续核对。详细边界见[上传结果确认](collector-upload-confirmation.md)与[长任务说明](long-tasks.md)。

### 服务端连接

工作台默认监听 `127.0.0.1:9812`。保存的采集端 URL 使用明确的私有局域网 IP 时，重启工作台会自动监听该地址；Windows 防火墙需允许对应 TCP 端口。

`WECOM_ARCHIVE_SERVER_LISTEN` 可显式覆盖监听地址。域名、公网地址和无效 URL 不会触发自动局域网监听；外网连接应使用 HTTPS。已绑定采集端会向配置的服务端同步心跳，上传需手动触发或启用计划。

## 数据保存与备份

运行数据位于程序同级目录，首次使用后生成：

| 位置 | 内容 |
| --- | --- |
| `serverData/` | 工作台配置、归档、媒体、采集端和导出文件 |
| `collectorData/` | 采集端运行配置和离线导出；仅使用工作台不会创建 |
| `source-roots.dpapi` | 加密保存的企业微信目录；移动程序时一并保留，换用户或电脑后重新填写 |

工作台数据目录可由 `WECOM_ARCHIVE_SERVER_DATA` 指定。采集在数据目录的 `work/<run-id>/` 处理只读副本，完成或失败后清理；采集端绑定配置由当前 Windows 用户的 DPAPI 保护。

在“设置 → 归档存储”打开备份与恢复窗口；无法正常启动时运行 `WeComArchive.exe --maintenance`。支持完整备份、校验和恢复到新目录，恢复首次启动须确认，并暂停计划及旧采集端。操作范围和跨机限制见[备份与恢复](backup-recovery.md)。

## 状态、日志与更新

- “归档健康”查看消息范围、缺失附件和磁盘余量，支持完整性校验。
- “任务中心”查看采集、上传、导入和导出记录；重启后未确认的任务显示“结果待核对”，不自动重跑。详见[归档与任务管理](archive-operations.md)。
- 日志默认关闭，可在采集端配置和管理中开启；`WECOM_ARCHIVE_COLLECTOR_LOG`、`WECOM_ARCHIVE_SERVER_LOG` 设置启动默认值。
- 工作台在“设置 → 关于”手动检查更新；采集端由管理员在管理页发起升级，保留数据和绑定配置。

| 日志 | 程序同级目录 |
| --- | --- |
| 采集端日志 | `collectorData/logs/YYYY-MM-DD.log` |
| 服务端日志 | `serverData/logs/server/YYYY-MM-DD.log` |
| 服务端接收的采集端日志 | `serverData/logs/collector/<collectorId>/YYYY-MM-DD.log` |

日志时间格式为 `yyyy-MM-dd HH:mm:ss.SSS`，不记录聊天正文、凭据、密钥或私人路径。程序不含遥测、远程字体或第三方资源；安全范围见[隐私与安全](privacy-security.md)。
