# 0.0.8 发布说明

## 新功能

- 自动读取企业微信设置中的存储目录，并保留原有默认目录。
- 本机采集和快速导出找不到数据时，可填写自定义目录重试，成功后通过 DPAPI 加密记住。

## 问题修复

- 多目录候选统一去重排序，优先当前数据，历史 Backup 数据保留为后备；手动重试仅扫描指定目录。
- 修复采集计划启用后未立即采集上传，以及任务忙碌时首次任务被跳过的问题。
- 修复首次空结果未上传、尚未上传成功却显示执行时间的问题。
- 管理页、采集端窗口和托盘统一显示“最近成功”；后台上传成功后清除首次上传失败提示。
- 精简采集端展示内容，最近成功独立换行，移除重复提示文字。

## 杂项

- 精简目录处理和状态代码，修正探测失败时工作目录的创建时机，更新相关文档与回归测试。
- 版本统一更新为 0.0.8。
- 发布为 Windows x64 单文件 EXE，无需解压。
- 当前安装包未进行 Authenticode 签名。

## 下载

下载 `WeComArchive-0.0.8.exe` 后直接运行。升级工作台后，请重新生成采集端 EXE，旧采集端不会自动更新。
