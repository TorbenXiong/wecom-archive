## 新功能

- 本机采集读取企业微信已缓存的语音转写文字，支持会话展示、全局搜索和导出。无需下载模型或配置在线转写服务。
- “包含全内容”支持采集本地已缓存的 SILK 原始语音，按消息摘要匹配以时间命名的缓存，支持归档和保存原文件。语音气泡可直接离线播放、暂停，显示总时长和已播放时间；最左侧下载图标保存原文件，转写文字在气泡右侧同一行显示，无需另选打开软件。

## 问题修复

- 修复 `content_type=16` 语音被归类为文件的问题；按 `message_table.server_id` 与 `msg_voice2text.message_id` 关联转写内容，过滤孤立转写，并兼容没有转写表的旧数据库。修复 [#19](https://github.com/TorbenXiong/wecom-archive/issues/19)。
- 补充显式撤回状态字段的读取，界面对已标记撤回的消息显示“消息已撤回”，隐藏正文和附件操作；`2063` 撤回事件显示为通知。没有明确撤回标志的原消息仍可能无法关联，不根据事件中的任意数字推断撤回对象。
- 修复语音仅按文件名查找、无法关联时间命名缓存的问题；补充受授权目录约束的内容 MD5 索引、SILK 文件头及大小校验，归档继续使用 SHA-256。远程访问凭据不进入归档。
- 后续仅文本采集、缓存过期或转写更新时，保留同一语音资源已归档的音频；没有本机缓存或匹配存在歧义时仍标记不可用，不自动联网下载。

## 下载

下载并运行 Windows x64 单程序 `WeComArchive.exe`。新目录首次运行会在 EXE 同级创建 `serverData/`；升级时先退出旧程序，替换 EXE，并保留原有数据和 `source-roots.dpapi`。

本版本保持数据库 v2 和四个归档契约兼容。旧归档需手动重新采集，才能补充已有转写并纠正语音类型；已有采集端需重新生成或升级。企业微信本机未生成或未缓存转写时，归档中仍没有转写正文。详细操作见 [人工验收清单](https://github.com/TorbenXiong/wecom-archive/blob/0.0.12/docs/acceptance-0.0.12.md)，限制见 [本机采集说明](https://github.com/TorbenXiong/wecom-archive/blob/0.0.12/docs/local-collection-fixes.md)。
