# 0.0.9 发布说明

## 新功能

- 全局消息搜索支持正文包含匹配、中文连续片段、英文词中片段、附件名称和 `%`、`_`、反斜杠等特殊字符。
- 全局搜索结果按每批 50 条加载，结果超过首批时可继续加载并保持稳定排序。
- 归档存储、服务端 API 和导出模块按职责拆分；消息分页、会话统计、FTS 行号映射和流式导出针对大归档做了优化。

## 问题修复

- 移除会话内“搜索当前会话消息”入口，避免与全局搜索产生重复入口和仅过滤当前页导致的漏搜。
- 修复全局搜索只返回前 50 条且没有继续加载入口的问题。
- 修复中文连续片段、英文部分词以及正文特殊字符无法命中的问题。
- 修复搜索关键词快速切换时旧请求结果混入新结果的问题，并对分页结果按稳定消息 ID 去重。
- 服务端通过已有 `source-windows` 路径依赖复用 Windows 加密、DPAPI 和默认应用打开能力；版本化归档契约和数据库 v2 保持兼容。

## 杂项

- 未新增第三方依赖；Cargo 锁文件仅同步工作区包版本和已有 `source-windows` 路径依赖。
- 构建和依赖解析使用 `--locked --offline`，发布包为 Windows x64 单文件 EXE；当前安装包未进行 Authenticode 签名。
- 正文包含匹配用于补足 FTS 的片段语义，大归档中的高频词搜索可能比纯索引命中更慢。

## 下载

请在全新的可写目录中解压并运行验收包。首次运行会在 EXE 同级创建 `serverData/`；不要把真实企业微信数据复制到发布包目录。此版本没有内置升级助手；安装包含升级功能的版本后，工作台可从 Release 更新，采集端可由服务端下发升级。
