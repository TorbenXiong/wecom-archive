# 0.0.12 人工验收

## 升级与重新采集

- 退出旧工作台（包括托盘），保留 `serverData/` 和 `source-roots.dpapi`，替换 `WeComArchive.exe`，确认版本为 `0.0.12`。
- 选取企业微信中已有转写文字的语音消息，手动重新采集。旧消息的类型纠正和转写补充需要重新采集，单纯替换 EXE 不会修改历史归档。
- 确认消息类型为“语音”，正文为本地转写文字；全局搜索可命中其中的独特片段，导出完整 JSON 的 `message_type` 为 `audio`、`raw_type` 为 `16`、`body_text` 为转写文字。
- 无转写的语音保留占位；没有 `msg_voice2text` 或 `server_id` 的旧库继续正常采集。转写表中没有对应消息的行不得生成额外消息。

## 撤回展示

- 对数据库中带显式撤回标志的消息重新采集，确认界面显示“消息已撤回”，隐藏正文和附件打开、保存操作。
- `2063` 事件显示撤回通知；事件中的发送人、时间等数字不得使无关消息被标记为撤回。删除标志不等同于撤回标志。
- 若本地库只保留撤回事件，未保留可验证的原消息关联或显式撤回标志，原消息的撤回状态仍可能无法补齐，不能据此宣称所有撤回场景已修复。

## 原始语音

- 在新工作台中执行“包含全内容”重新采集，选择本机已缓存的语音；确认同一行依次显示下载图标、时长、浅蓝语音气泡和转写文字。已有原始语音的归档升级后无需重新采集。
- 点击气泡直接在程序内播放，不弹出系统应用选择；播放时显示已播放时间及声波动画，再次点击暂停，再次点击继续。播放另一条时前一条暂停，结束后恢复总时长。
- 点击最左侧下载图标只保存原文件，不触发播放；不再在下一行显示“保存语音”。断网时播放不依赖第三方服务，切换会话或页面后停止播放。
- 保存文件的扩展名为 `.silk`，字节与企业微信本地对应缓存一致；播放生成的 WAV 只作为临时播放资源，不替换归档原文件。解码失败仍可保存原文件。
- 再次仅采集文本，确认已归档的语音仍可保存；同一资源的转写更新不能丢失已采集音频。
- 缓存缺失、文件头或大小不符、内容摘要不匹配、多候选歧义时保留不可用状态；不得把另一个账号或仅文件名相似的文件归到该语音。

## 已确认的限制

- 用户已确认转写及原始语音采集成功；此前生产代码只读核验已成功取得已定位的 11,591 字节 SILK 样本，并确认 SHA-256。本轮播放、暂停和保存原文件仍需在新桌面包人工验收。
- 已验证按消息摘要关联的本机 Voice 缓存；不代表所有企业微信版本、缓存结构或音频编码均已适配。内置 SILK 离线解码，不提供自动语音识别；播放限制为 10 MiB、10 分钟，超出限制仍可保存原文件。
- 不采集或提交真实消息、账号、密钥、私人路径或截图作为测试产物。
