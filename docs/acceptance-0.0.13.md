# 0.0.13 验收清单

本版变化见 [版本说明](release-0.0.13.md)，已执行结果及覆盖边界见 [验收记录](acceptance/0.0.13-results.md)。本页是操作标准，不表示每项已在每个构建上重新执行。

## 准备

正常退出旧工作台后替换 `WeComArchive.exe`，保留 `serverData/` 和 `source-roots.dpapi`；在“设置 → 关于”确认版本 `0.0.13`。新目录运行使用独立数据位置，不会自动迁移旧归档。不要同时运行监听同一端口的旧、新工作台。

浏览可使用已有归档；导入、导出、异常注入和设置修改使用合成数据或程序完整停止后的测试副本。需要加密包绑定时保留配置并使用同一 Windows 用户。`WECOM_ARCHIVE_SERVER_DATA` 会覆盖默认数据目录，应确认其指向测试位置。

启用超管模式，准备至少 120 个会话、5,000 条消息及已知样本：高频正文、中文片段、旧稀疏词、附件名、同时间记录、共享附件、跨页引用。导入正例使用本版关闭“简化信息”后导出的完整 JSON，或同一测试绑定生成的 `.wca`。缺少条件的项目记录“未覆盖”。

## 启动、目录和选择

| 编号 | 操作 | 通过标准 |
| --- | --- | --- |
| L01 | 启动、切换会话，退出后重开。 | 版本及会话、消息、媒体计数与基线一致，配置和已有归档可用。 |
| L02 | 首次打开超过 50 个会话的目录，先使用首屏。 | 首批 50 行可用，显示完整会话总数，不自动循环读取全部页。 |
| L03 | 滚动到底，快速重复点击继续加载直至末尾。 | 无重复、遗漏或选择跳动，同一页不并发重复请求；末尾停止请求。满页末尾允许一次空页确认。 |
| L04 | 阻断追加或刷新请求，再恢复并重试。 | 已有列表和选择保留；失败有提示，后续加载从原偏移继续，不被旧在途响应覆盖。 |
| L05 | 选中首批之外的会话，另一个认证客户端导入数据。 | 更新后保留原会话并刷新消息，必要时额外保留选中行。 |
| L06 | 延迟一次追加响应，其间刷新目录或切换页面。 | 取消旧请求；迟到结果不能改写新目录，后续加载正常。 |
| P01 | 在搜索筛选中继续加载，选后续会话和发送人。 | 会话及其成员可选，结果满足筛选。 |
| P02 | 保留搜索会话筛选，导入触发目录刷新。 | 所选值和名称保留，不悄悄改为全部会话；不要求现有搜索结果自动重新查询。 |
| P03 | 导出多选中加载后续会话，勾选两项、取消一项。 | 显示的已选数正确，实际导出只包含最终选择。 |
| P04 | 多选导出保持打开，导入触发目录刷新。 | 首批之外的勾选项仍可见、选中并能取消。 |
| P05 | 未加载完整目录时导出全库、当前会话和单日范围。 | 全库不受已加载目录限制，当前会话包含其他消息页，日期及完整计数正确。 |

## 搜索及定位

通过工具栏或 `Ctrl+Alt+F` 打开搜索，核对已知目标，不只依据结果条数。

| 编号 | 操作 | 通过标准 |
| --- | --- | --- |
| S01 | 搜索高频正文词。 | 首屏可用，结果满足原匹配规则；不提前批量计算每条结果的会话内位置。 |
| S02 | 中文词内片段、英文内部片段及大小写变体。 | 已知消息可找到，维持原大小写行为。 |
| S03 | 只在附件名出现的片段，含无本地字节的附件。 | 按已归档名称找到对应消息。 |
| S04 | 正文和附件名同时命中，多消息共享同一附件。 | 同一消息不重复，不同消息均保留。 |
| S05 | 搜索目标前有数千条不命中记录的稀疏旧词。 | 窗口之外的目标仍能找到。 |
| S06 | 搜索不存在的独特词。 | 显示无结果，无旧结果残留或异常。 |
| S07 | `cafe` 对 `café`，`alpha beta` 对 `alpha middle beta`。 | 保留重音折叠及多词分词语义。 |
| S08 | `100%_value`、`C:\fixture\files` 和双引号样本，配无关对照。 | 无语法错误或 LIKE 通配扩散，维持原 FTS 命中规则。 |
| S09 | 组合会话、发送人、类型、附件、日期和关键词，再重置。 | 条件同时满足、边界日期正确、重置完整；错误日期范围有提示。 |
| S10 | 至少三批搜索结果，切换全局升降序。 | 跨页稳定有序、无重复遗漏，包含同时间样本。 |
| S11 | 点击尚未加载会话中的搜索结果，定位期间关闭搜索。 | 正确会话、页码和高亮；取消后的迟到定位不覆盖新选择。 |
| S12 | 延迟词 A 的响应，改词 B、清空，再关闭。 | A 不能覆盖 B，清空或关闭后不回流旧结果。 |
| S13 | 辅助请求检查 offset 4095/4096/4100，配 limit 1/50。 | 与完整结果切片一致，不被 4,096 上限截断。 |
| F02 | 点击跨页引用，切换升降序和每页 100/200/500 条；再测取消、手动翻页和失败重试。 | 按当前分页跳转并高亮，同页不额外定位；迟到响应不覆盖后续操作，错误可重试。 |

## 导入、导出和回归

| 编号 | 操作 | 通过标准 |
| --- | --- | --- |
| I01 | 分别导入合法完整 JSON 和同绑定 `.wca`。 | 完成并得到预期统计和内容。 |
| I02 | 重复提交相同文件。 | 新增 0，普通未变内容不形成修订，目录及媒体关系正常。 |
| I03 | 修改 `batches[0].messages[0].body_text` 但不重算校验；另测空文件和坏包。 | 拒绝且不入库，任务结束后本次接收及 `.partial` 文件清理。 |
| I04 | 失败后立即导入合法小包。 | 按钮恢复，名额释放，导入可继续。 |
| I05 | 两个认证客户端先发受控慢包再发小包，至少一次混用 JSON 和 `.wca`。 | 后包等待，最终无丢包、重复或死锁。单个页面按钮禁用不代表并发已测。 |
| I06 | 耗时导入期间切换设置和会话，观察内存。 | 窗口可交互，包不同时解析；单包内存可随大小增长，不要求恒定内存。 |
| I07 | 接收未完成时断开，再提交完整文件。 | 半包不入库，临时文件清理，后续导入可继续。 |
| I08 | 确认接收完成、处理未结束时断开，再发一包。 | 后台允许继续，名额持有至任务结束；后续请求等待，重复导入幂等。 |
| F01 | 关闭简化后，五种范围导出 JSON，分别导回原库和空库。 | 校验通过，计数及目录正确，原库重复导入不产生无故新增或修订；篡改内容仍拒绝。 |
| R01 | 四种格式、独立排序、简化和脱敏，核对大于 4,096 条的完整输出。 | 范围、顺序、转义和计数正确；简化 JSON 仍为阅读格式。 |
| R02 | 在非空 `.partial` 已产生时取消；保留已有完成文件和其他写入者的 partial。 | 清理本次暂存、不产生本次完成文件、不覆盖或删除他人文件。 |
| R03 | 成员名片、图片、附件、引用及语音播放和保存。 | 内容与操作正确；语音另需人工听音。回归转写和撤回时参照 [0.0.12 清单](acceptance-0.0.12.md)。 |
| R04 | 关闭超管模式，再开启。 | 关闭后目录可见，消息/搜索/导出隐藏且接口拒绝越权；开启后恢复。 |

当前没有新增导入取消按钮或排队进度；断电或强制终止后的崩溃恢复不属于本版新增保证。完整服务端 JSON 只含媒体引用，迁移离线媒体仍需保留原媒体库。

## 辅助验证

已有本地工具和依赖时，在 PowerShell 执行：

```powershell
./scripts/benchmark-search-api.ps1 -Counts @(1000, 100000) -QuerySamples 5
& "$env:USERPROFILE/.cargo/bin/cargo.exe" test -p archive-store --locked --offline ordered_search_pages_match_complete_results_across_filters_and_prefix_boundaries
```

工具或缓存缺失时停止并记录原因，不自动下载。性能前后比较须同机、同数据及条件，各重复五次取中位数；输入防抖及渲染不包含在 HTTP 时间中。稀疏词、零命中、深页、计数和导出没有同等提速并不代表结果错误，测量边界见 [搜索基准](search-api-benchmark.md)。

每项记录通过、失败或未覆盖，明确真实/合成数据、注入错误、样本规模和耗时。不得保存真实聊天、账号、认证头、密钥、私人路径或截图。
