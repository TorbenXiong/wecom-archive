# 0.0.11 人工验收

## 准备

使用已授权的测试账号及合成消息。升级前退出旧程序并备份数据，保留 `serverData/` 和 `source-roots.dpapi`；全新目录初始只放一个 `WeComArchive.exe`，首次运行确认版本 `0.0.11`，仅工作台不应创建 `collectorData/`。

验证远程采集端时重新生成测试端，或从支持升级的 `0.0.10` 测试升级。两个工作台应使用不同端口，采集端应使用独立可写目录。

## 场景与标准

| 场景 | 操作与通过标准 |
| --- | --- |
| 单次全内容采集 | 先在企业微信下载测试图片及附件，再执行“包含全内容”。弹窗显示进度，任务结束后文字、关系、图片和附件一起可用；没有后台补采任务。 |
| 媒体关联 | 检查此前缺失的图片、自定义表情和重命名缓存附件；成功归档后再执行“仅采集文本”，已有媒体仍可用。源文件确实缺失时显示原因。 |
| 脱敏与富文本 | 分别开、关本次脱敏开关采集；用虚构敏感值确认占位符，并确认 `[便便]99345`、纯数字和重复表情完整显示。 |
| 附件操作 | 普通文件能打开、保存；安装包打开前需确认，取消不运行，保存也不运行。实际安装仅由用户确认来源后验证。 |
| 会话分类 | 对照文档标题、个人应用“应用名-用户名”、无名群成员组合、临时会话及系统通知；列表和时间线标签一致，不将应用或通知误认成群。 |
| 人员名片 | 姓名下为企业，资料依次显示部门、职务、邮箱、工号、手机、电话、座机，最后显示归档标识及身份；空值隐藏，按需显示但未落入本地缓存的号码不作为通过要求。 |
| 同 IP 多采集端 | 两台电脑或虚拟机的不同实例经同一 NAT/代理连接，等待多轮心跳及上传，再重启一端。两条记录均持续保留。单机互斥不能用于模拟双端。 |
| 断线与配置过期 | 中断测试端连接至少一次心跳后恢复；进程保留并自动重连。离线超过控制配置有效期后暂停新采集，恢复有效配置后继续。 |
| 桌面权限 | 在回环地址、局域网、自定义端口及可用 IPv6 地址启动测试工作台；退出、检查更新命令可用，其他来源页面不获得权限。 |
| 基础回归 | 浏览、全局搜索、翻页及脱敏 HTML/CSV 导出可用；关闭采集端窗口后仍驻留托盘，从托盘退出后进程结束。 |

修订循环、长任务增量边界、失败不推进游标、明确吊销停止采集端，以及请求令牌不进入 curl 参数，均有合成回归测试覆盖，无需人工修改源库或展示真实令牌。

升级替换、回滚与错误资产场景见 [升级测试方案](update-test-plan.md)，离线能力限制见 [本机采集说明](local-collection-fixes.md)。各项记录“通过 / 失败 / 未验证”；没有多设备或可信升级源时保持“未验证”，反馈仅保留版本、步骤及脱敏错误。
