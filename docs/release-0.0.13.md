## 新功能

- 会话目录首批加载 50 条，滚动或点击继续加载，失败可重试；搜索筛选和多选导出可选择后续会话，归档刷新后保留当前选择。
- 引用消息支持按当前排序和每页数量跨页定位及高亮，提供取消、失败提示和重试。

## 问题修复

- 修复服务端完整 JSON 无法重新导入的问题；关闭“简化信息”后保留会话阅读视图、原批次、成员目录、时间精度和完整校验。五种导出范围均适用，取消清理且不覆盖已有文件。
- JSON 和 `.wca` 导入从接收至归档完成共用一个名额，耗时处理移至后台线程；失败和接收取消后释放名额并清理临时文件。
- 提升高频正文、中文片段、附件名及组合筛选的搜索性能，保留 FTS 分词、原有排序和完整结果；稀疏词及深分页仍可回到完整查询。
- 修复目录刷新失败后的继续加载，并阻止目录、搜索和引用定位的迟到响应覆盖新操作；已脱敏路径摘要保持幂等，避免无故修订。

## 下载

下载并运行 Windows x64 单程序 `WeComArchive.exe`。新目录首次运行会在 EXE 同级创建 `serverData/`；升级时先退出旧程序，替换 EXE，并保留原有数据和 `source-roots.dpapi`。

本版本保持数据库 v2 和四个归档契约兼容，无需为本次优化重新采集。旧程序生成的不含契约的服务端阅读 JSON 需重新导出；简化 JSON 仍仅供阅读。服务端完整 JSON 只含媒体元数据和引用，迁移离线媒体时仍需保留原媒体库。详细操作见 [人工验收清单](https://github.com/TorbenXiong/wecom-archive/blob/0.0.13/docs/acceptance-0.0.13.md)，验证范围见 [验收记录](https://github.com/TorbenXiong/wecom-archive/blob/0.0.13/docs/acceptance/0.0.13-results.md)。
